# GUI 更新與版本恢復

GUI 更新先下載並驗證新的版本目錄，經使用者確認及原 owner 的培育／未決操作檢查後，才切換 `active.json`。舊版本與使用者資料保留；切換不會自動重啟目前視窗或遊戲。

如果目前版本無法通過完整性檢查，啟動器會先驗證保留的前一版。只有前一版完整時，才顯示「開啟前一版恢復介面，尚未切換版本」的確認。使用者同意後只啟動這個已驗證的 GUI；尚未修改版本指標，也不會要求 UAC、啟動遊戲或執行維護。沒有有效前一版時保留原錯誤。

若目前版本的檔案完整但 GUI 實際啟動失敗，可雙擊安裝目錄中的「恢復 GUI.cmd」，或明確執行 `GKMS-Assistant.exe --recover`。這個入口同樣先完整驗證前一版、要求確認，再開啟恢復介面；不會自動切換版本。一般啟動不會因存在前一版就詢問回退。

恢復介面會顯示明確提示。請等培育及未決操作完成，再按「回退上一版」並確認。回退會驗證前一版，不要求已損壞的目前版本重新通過檢查；一般更新仍必須驗證目前版本。

切換前先保存包含原指標與預期新指標的操作紀錄。版本指標切換成功後，若狀態或回執儲存失敗，介面會顯示「已切換」及保存警告，不會要求重送。下次啟動只讀取原指標並核對原操作，修復狀態紀錄；不重放切換，也不執行遊戲操作。
