# Public outer-policy dependencies

The current source is Master `12b24ff515f7dcdc2aa107bdea1745fb2f6177cab1f6381ae709ef8b223d7aa8`.
Its independently pinned export is `portable_outer_assets_v2_12b`, manifest
`1dcfa769f87e52fd5beb8931581bc7d24745621104fae830c54cd0ea24783abb`.
The original weekly weights, count prior and deck references are unchanged.
Per the updated delivery scope, memory selection uses the game's own automatic
recommendation: the learned memory prior is neither packaged nor required by
the AP preflight. Its former v1 projection remains historical evidence.
The older 17c/62-case comparison below records the previous migration only;
the separate 12b audit records new source hashes and unchanged existing rules.

The public outer package is separate from the unchanged exam-model v4 and
loadout packages. It contains 30 required Master YAML tables, the existing
weekly BC inference weights and coverage, and qualified projections of the
hierarchical behavior counts and whole-deck references.
Original observations, raw replays, player identifiers and machine source
paths are not distributed.

The rule tables retain the exact bytes of verified Master
`17c7e42075b22536fa0722b3a8e7d43f1963064a5985ec67f23e684e9eccd9ae`.
Historical behavior priors retain their original source versions and coverage;
they are not relabelled as training on this current Master. The weekly model
bytes and all existing prior scoring remain unchanged. No retraining,
collection or training admission occurs during export.

`portable_outer_assets.py` pins the package manifest. The shared application
path resolver uses its Master directory in public installs and retains the
development path outside a public install. The model's 20 frozen numerical
source files are unchanged. An explicit Master directory is propagated through
the outer context to deck evaluation, avoiding a mixture of old and current
rules.

Before `produce.start` can spend AP, the runner verifies every required file,
typed behavior projection, weekly provider and mode/idol source. Missing public
assets stop the operation before recorder/model RPC or Start dispatch.
Selected public priors also raise on damage during later decisions instead of
silently falling back to missing development data. Uncovered behavioral scopes
still retain the original explicit abstention policy.

The v6 audit used an existing completed-run snapshot and found a missing
`Produce.yaml` blocker plus unavailable weekly/count priors. The correction is
not merely packaging more exam weights. The 62 retained-case comparison uses
the same verified current Master and database on both sides, with original
historical priors versus their public projections: all 62 targets/guard outcomes
match. There are 61 returned targets and one intentionally retained rejection
for a shop-finish confirmation without its caller-bound submitted intent.

Eighteen of the 30 current tables differ from older implicit development YAML.
This comparison therefore does not claim equality with the old trial's stale
Master mix, a new live workflow result, training qualification or score gains.
All verification is file-only and uses existing observations; no native input
or server operation is submitted.
