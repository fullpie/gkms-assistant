# GKMS Assistant 0.2.0

[繁體中文](README.md) · [English](README.en.md) · **日本語**

『学園アイドルマスター』PC 版の自動育成アシスタントです。共通の深層強化学習モデル **RL_v1** がサポート・メモリー編成、対応済みの育成行動、試験中のカード・ドリンク・付随選択を判断します。既存の DLL がゲーム状態の取得と操作を行います。

## 主な機能

- アイドル選択から育成、試験、報酬受け取り、ホームへの復帰まで自動実行。
- モードと試験段階を入力条件とする、6 種類の育成タイプ共通のモデル。
- 実際に所持するサポート・メモリーと現在利用できるレンタルから編成を提案。固定・除外設定にも対応。
- 使用モデル、進行状況、停止理由、未校正の予測スコアを表示。
- ゲーム起動、任意の翻訳、操作モジュールの導入、GUI 更新を統合。

モデルの対象は N.I.A. Pro／Master です。RL_v1 は学習と独立したデータ評価を完了していますが、RL_v0 を安定して上回ることは確認されていません。一部の対戦ではスコアが低く、ドリンク戦略も改善が必要です。一部の付随選択は学習データが不足しており、クリアや高得点を保証しません。実行中の学習・モデル差し替えは行わず、旧 BC の選択も無効です。

ゲームデータのバージョン更新だけを理由に利用を止めることはありません。対応するカード・効果は同梱の参照データで処理します。判断に必要な新カード・ドリンク・効果の定義が未収録の場合は、不足項目を示して停止します。実際のゲームと参照データのバージョンは別々に記録します。ゲーム本体やインターフェースが非対応の場合も停止し、不足情報をゼロやルール判断で埋めてモデル推論と称することはありません。

## 使い方

1. [Releases](https://github.com/fullpie/gkms-assistant/releases) から Windows 用の完全版パッケージを取得し、すべて展開します。
2. `GKMS-Assistant.exe` を起動し、ゲームフォルダーを指定して必要な操作モジュールを導入します。
3. アイドル、モード、回数を選択し、編成を確認して開始します。

Windows x64、Microsoft Edge WebView2 Runtime、.NET Framework 4.7.2 以降が必要です。GUI は独立したウィンドウで通常権限により動作します。ゲームの保守操作では管理者権限を求める場合があります。EXE だけを移動せず、フォルダー全体を保持してください。更新後に起動できない場合は `恢復 GUI.cmd` を使用できます。

固定済みの推論パラメーター、必要な静的データ、CPU 推論ライブラリを同梱し、Python や NVIDIA GPU の導入は不要です。学習 checkpoint・optimizer、個人用研究機能、アカウント情報、学習リプレイ、テスト DLL、個人用ネイティブ探索は含みません。編成は同じモデルで直接推論します。

独自部分の権利は留保されています。第三者コンポーネントには各ライセンスが適用されます。開発者向け情報は[ビルド手順](docs/public-gui-packaging.md)を参照してください。
